# Irrationality of √11

**Theorem.** The real number $\sqrt{11}$ is irrational.

**Proof sketch.** Since $11$ is a prime number, it is not a perfect square. A standard
result states that for a natural number $n$, $\sqrt{n}$ is irrational whenever $n$ is not a
perfect square. Because $11$ is prime, hence not a perfect square, $\sqrt{11}$ is irrational.
